[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/TheDataBadger/DSPP/blob/main/Childcare_Affordability_and_National_Happiness_(K_Means).ipynb)

📊 **Project Overview:**  
This project explores how childcare affordability relates to broader wellbeing indicators, including life expectancy and happiness. 
The analysis uses international datasets to cluster countries in the OECD via K-means, using data Childcare costs as a % of disposable household income, and World happiness data.
